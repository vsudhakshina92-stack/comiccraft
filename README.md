# ComicCraft ✨ – AI Comic Story Creator

ComicCraft is a web-based AI comic story creator that transforms a user's idea into a four-panel comic story. Users can create a character, choose a setting, select a tone and art style, and generate a comic based on their story prompt.

## 🚀 Features

- Create comic stories from user prompts
- Add a custom comic title
- Create a main character
- Choose a story setting
- Select the story tone
- Choose different art styles
- Generate a four-panel comic story
- Preview the generated comic
- Customize or regenerate the story
- Download the comic
- Export the comic as a presentation-ready PDF

## 🎨 Available Art Styles

- Comic Book
- Anime
- Cartoon
- Manga
- Watercolor

## ⚙️ How It Works

### 1. Describe
Enter the comic title, main character, setting, tone, and story prompt.

### 2. Generate
ComicCraft converts the idea into a four-panel story with four story beats.

### 3. Customize
Edit the story details or generate a new story direction.

### 4. Export
Download the completed comic or export it as a PDF.
